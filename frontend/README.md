# Tactical WiMAX QoS - Frontend

React + Vite dashboard for the project results (PBS vs NSGA-II).

## Run
    npm install
    npm run dev

## Build for hosting
    npm run build     # output in dist/

Data is stored as constants at the top of src/TacticalWimaxDashboard.jsx.
All figures come from simulation, not physical WiMAX equipment.
